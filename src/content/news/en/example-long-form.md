Use this template for a longer piece, such as a write-up of a workshop, an opinion piece, or lessons learned from a project.

## Why we wrote this

Start each section with a `##` heading. Readers can skim the headings to find the part they care about.

## What we found

Lists work for short points:

- First point, kept to one line
- Second point
- Third point

Numbered lists work for steps:

1. Download the tool
2. Connect the device
3. Run the scan

> Quotes are useful for pulling out a key sentence or citing someone.

## Code and commands

Wrap commands in three backticks:

```bash
adb devices
```

## Next steps

End with what the reader should do or watch for next.
