MESHdrop is private file transfer between two computers, with no cloud, no account, and no trace left behind. It is a desktop application built on [MESHnet](https://github.com/BARGHEST-ngo/MESHnet).

The file goes straight from one desktop to another, wherever they are, without uploading to a third-party service first. The sender picks a file and gets a link and a 6-digit PIN, shares both with the receiver over any channel they trust, and the transfer runs once the receiver connects and accepts. There is nothing to sign up for.

MESHdrop is in early alpha. It works end to end, but it has not yet been widely tested.
